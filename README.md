# 钢包红外热像在线监测系统

面向冶金钢包吊运场景的红外序列处理系统：从原始温度矩阵序列中分割钢包、展开包壁、
跨帧对齐同一耐材点、按发射率/烟尘修正测温、检测热点并在超阈 3 秒后报警，
同时按钢包编号建档、记录每炉最高温与热点位置、基于温度趋势给出换砖预警。

## 技术栈

- TypeScript + Vite，严格类型（`strict`）
- 图像处理：WebGL2 浮点管线（`src/webgl/gpuEngine.ts`），CPU 管线作为同构基准与降级路径
- 纯 TS 合成数据引擎（无外部素材依赖），真值旁路仅供测试，处理管线不读取

## 目录结构

```
src/
  core/        领域类型、回转截锥几何、辐射域测温修正、温度场、档案与磨损趋势、报表
  synth/       合成序列引擎（摆振/自转/烟尘/硬遮挡/天车钩子）、.lirs 容器
  pipeline/    分割与钩子剔除、位姿跟踪、yaw 环形 NCC、包壁展开、融合、热点与报警
  webgl/       WebGL2 着色器：分割 / 透过率 / 展开反演（R32F/RGBA32F 浮点 FBO）
  web/         UI、热图渲染、Worker、IndexedDB 档案、.lirs 导入导出
tests/         Vitest：辐射模型、报警时序、yaw、容器往返、档案、端到端
```

## 核心设计

### 几何与展开
钢包外壁建模为回转截锥体（`rBottom→rTop`，高 H），规范坐标为环向角 φ（360 列）
× 高度 h（96 行），耐材砖格 60×12。分割用「温度阈值 + 连通域 + 截锥包络 + 包口线」
四重约束：包口线上方、与包壁包络重叠不足的独立高温域判为天车钩子并剔除。

### 测温修正（辐射域 T⁴）
在 Stefan–Boltzmann 四次方域而非线性温度域反演：
`M_meas = τ·(ε·M_wall + (1−ε)·M_refl) + (1−τ)·M_smoke`，
烟尘透过率由同高度带干净参照反演，避免低温段线性近似的系统偏差。

### yaw 跟踪（环形 NCC）
零 yaw 投影的展开图保留完整自转信息；在恒速预测的环形窗口内对滚动锚点做
归一化互相关（NCC），直接输出绝对 yaw，无增量积分漂移；滚动锚点仅在高相关分时
更新，覆盖随自转进入视野的新方位，同时避免错误配准污染基准。硬遮挡时占用率门限
冻结平移/尺度拟合并按恒速外推，热点温度由跨帧融合图记忆保留。

### 报警
逐像素状态机：温度超过阈值且持续 `alarmHoldSec`（默认 3s）才报警，记录超阈起点到
报警的实测时延、温度与热点环向位置；超阈中断后重新计时。

## 关键指标（Vitest 端到端，合成真值校验）

- 可见热点辐射校正误差 ≤ 6 K（满足 ±5°C 量级要求）
- 纯旋转序列 yaw 平均误差 < 5°
- 报警时延 2.9–3.4 s，贴合 3 s 门限
- 半程硬遮挡期间融合图温度记忆保持率 ≥ 85%，热点不丢
- 天车钩子高温像素被连通域规则剔除，不进入包壁掩码
- CPU 基准管线每帧 < 100 ms（320×240，Node 实测约 45 ms）

> 说明：强摆动 + 重烟尘叠加的长序列下，纯纹理 NCC 的绝对 yaw 会退化（半圈视野与
> 锚点重叠衰减所致）。工程部署建议引入人工/自然方位标记或特征点配准，本仓库的
> yaw 模块已预留滚动锚点与窗口约束接口，可平滑替换。

## 数据格式 `.lirs`

小端二进制：文件头（magic `LIRS1` + 几何/帧率/场景）+ 每帧 `f64 tSec` + `f32[width*height]`，
支持 Blob 切片随机读（`LirsReader`）。真值通过独立 JSON sidecar 旁路保存，不进入处理链路。
